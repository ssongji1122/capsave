# Scrave 앱인토스 네이티브 이식

기존 모바일의 정리 화면·검색·목록 판정과 웹의 분류 도형을 재사용하며, 앨범 선택·기기 저장·복사·외부 링크를 토스 연결 도구로 바꿉니다. 기존 Expo 앱의 설치 파일은 변경하지 않습니다. npm 작업 공간에 포함되는 `apps/*`와 분리해 공식 빌드 도구의 중첩 설치 충돌을 피했습니다.

현재는 등록 전 기기 보관함 시험판입니다. 자동 분석·서버 보관함·로그인·지도 화면·내 가이드를 토스에 연결하지 않았으며 전체 앱 이식이나 출시 완료를 뜻하지 않습니다. [전체 작업 기록](../../docs/coordination/2026-10-30_scrave-mobile-toss-integration.md)에서 기존 모바일 통합 결과와 구분합니다.

## 실행과 검사

Node.js 24에서 이 폴더의 고정 설치 파일을 사용합니다. `.npmrc`는 2026-10-23 이후 배포된 패키지를 제외합니다. 고정한 직접 의존성과 기존 Expo의 버전을 섞지 않습니다.

```sh
nvm use 24
npm ci --workspaces=false
npm test
npm run typecheck
TOSS_APP_NAME=scrave-local npm run build
```

마지막 명령은 등록 전 검사 전용 이름으로 `scrave-local.ait`를 만듭니다. 등록 후에는 콘솔의 실제 앱 이름과 아이콘을 설정하고 다시 빌드합니다. 현재 브랜드 아이콘은 빈 값이며 공개 배포용 구성이 아닙니다. 빌드는 로컬 파일 생성까지 진행합니다.

```sh
TOSS_APP_NAME=콘솔의-실제-앱-이름 npm run dev -- --host localhost
```

[공식 샌드박스 안내](https://developers-apps-in-toss.toss.im/development/test/sandbox.html)에 따라 개발자 계정 로그인·등록 앱 선택·토스 본인 확인을 마친 뒤 실행합니다. 비밀번호·인증번호를 문서나 채팅에 남기지 않습니다.

## 저장과 실패 처리

사진은 토스 앨범에서 한 장씩 선택하고 최대 너비 2048px의 Base64 데이터를 기기 보관함에 저장합니다. Base64는 이미지를 글자로 변환하는 저장 형식이며 입력 파일의 원본 바이트를 그대로 보존한다는 뜻은 아닙니다. 제목·필요한 글·출처 주소를 직접 입력하고 기존 Scrave와 같은 메모·예약번호·처리 상태·여행 묶음 기능을 사용합니다. 이미지는 기기에 보관하며 유료 분석을 호출하지 않습니다.

파일 경로가 만료돼 사진이 사라지지 않도록 이미지 내용을 함께 저장하며, 저장 성공 응답을 받은 뒤 목록을 갱신합니다. 저장에 실패하면 선택한 사진과 입력 내용을 유지합니다. 쓰기는 순서대로 처리하며 잘못된 보관함 데이터가 있으면 덮어쓰지 않습니다. 같은 이미지의 중복 저장을 방지합니다.

토스 `Storage`의 실제 저장 한도와 계정 전환 범위는 아직 실측하지 않았습니다. 이 버전을 계정별 비밀 보관함으로 안내하지 않습니다. 이미지가 늘면 문서 전체를 다시 기록하는 방식의 비용과 용량을 확인한 뒤 저장 방식을 결정합니다.

## 검증 범위와 남은 제약

검사는 대체 저장소·대체 토스 연결 도구를 사용하는 기능 검사와 실제 공식 도구의 두 실행 기반 빌드를 구분합니다. 실제 토스에서 사진 권한 거부·취소·복사 거부·앱 재실행·저장 공간 부족을 확인해야 합니다. 자동 분석과 기존 계정 연결은 별도 인증 설계·승인 후 구현합니다.

흰 바탕·슬레이트 색·사진 전체 표시·2열·공통 분류 도형·기존 손그림과 정리 화면을 연결했습니다. 기존 화면의 SUIT 글꼴 지정은 유지하지만, Expo의 글꼴 등록 도구를 토스에 포함하지 않았습니다. 토스가 사용자 글꼴을 지원하는지와 실제 표시를 확인하기 전에는 디자인 일치를 완료로 판정하지 않습니다. 글꼴 정책을 바꾸려면 사용자가 방향을 결정해야 합니다.

설치 직후 `npm audit`는 전체 의존성 46개에 경고를 보고했습니다. 심각도는 낮음 16개·보통 8개·높음 21개·치명적 1개입니다. 이는 검사 도구의 보고이며 실제 앱의 악용 가능성을 검증한 결과는 아닙니다. 치명적 경고는 개발 서버의 `@fastify/middie` 하위 의존성에 있습니다. 버전 강제 변경을 하지 않았으며 공개 배포 전 영향과 수정 호환성을 별도로 확인합니다. [관련 보안 공지](https://github.com/advisories/GHSA-72c6-fx6q-fr5w)를 함께 참고합니다.

재검토일은 2026-11-02입니다.
