## 그대로 병합할 때의 위험

PR #30은 최신 가이드 저장 타입과 갤러리 타입이 들어오기 전 기반에서 시작했습니다. 충돌을 PR 쪽 내용으로 일괄 해소하면 `ready` 상태, 공개 범위, 저장 가이드 타입, 묶음 갤러리 필드를 잃을 수 있습니다. 좌표 요청도 PR은 여러 장소를 동시에 처리하고 현재 브랜치는 순서대로 처리하므로, 호출량과 오류 격리 방식이 달라집니다.

현재 API는 요청별 인증 클라이언트를 사용합니다. PR 쪽 구현으로 바꾸면 인증 테스트 어댑터가 달라지므로 별도 근거 없이 교체하지 않습니다.

## 추천 처리

PR #30은 현재 브랜치에 그대로 병합하지 않는 것을 추천합니다. 좌표 저장과 30일 만료라는 목적은 현재 구현과 119개 표적 테스트가 이미 충족합니다. PR에만 있는 고유 요구가 없는지 작성자가 확인한 뒤, 현재 구현으로 대체됐음을 남기고 닫는 편이 안전합니다.

PR 닫기는 외부 변경이므로 이 감사에서는 실행하지 않았습니다.
