## 목표와 범위

사용자가 승인한 흰 바탕·슬레이트 블루·SUIT·가늘고 선명한 손그림을 웹과 Expo 앱에 연결하고 휴대폰에서 열리는 기존 운영 주소로 제공합니다. my craves는 보관함 이름이며 제품 이름은 Scrave입니다. 다이어리 꾸미기용 100종을 별도 스티커북과 개별 투명 PNG·ZIP으로 제공합니다.

담당은 이 Codex 대화 세션 01a16d26-e9fa-74e0-a036-9dd6281ddbc9입니다. 원래 작업 폴더의 혼합 변경은 보존하고 최신 origin/main 6c5322c에서 feat/slate-sticker-design 작업 공간을 만들었습니다. 운영 배포는 사용자의 휴대폰 주소 요청에 따른 기존 Vercel Scrave 경로를 사용하며 새 외부 서비스를 만들지 않습니다. 공개 GitHub PR 생성·원격 푸시는 실행하지 않습니다.

## 완료 기준과 검증

- 웹·모바일의 흰 바탕, 슬레이트 브랜드 색, 함께 포함한 SUIT와 라이선스를 확인합니다.
- 카드 시작점과 제목 영역을 맞추고 웹 3~4열·모바일 2열을 확인합니다.
- 기존 캡처 추가·자동 분류·원본·정리 내용·출처·지도·가이드 코드를 재사용합니다. 시각 변경 검증에서 유료 분석을 새로 호출하지 않습니다.
- 공유 테스트 242개, 웹 테스트 450개, 모바일 테스트 79개가 통과했습니다. 웹의 기존 보류 테스트 3개는 그대로 두었습니다.
- 세 패키지 타입 검사와 웹 운영 빌드를 통과했습니다. Expo iOS export에서 SUIT 3종과 그림 8종을 포함한 번들을 생성했습니다.
- 100개 개별 PNG에서 파일 판독·알파 채널·최소 크기를 검사했습니다. 내장 image_gen으로 시트 10장(100종)을 생성했으며 앱 시트 수정 1장을 별도로 만들었습니다.
- 로컬 모바일 너비 390px에서 가로 넘침이 없고 카드 시작점과 제목 시작점이 동일함을 측정했습니다. 원본·출처 패널을 펼쳐 링크와 로그인 안내가 보임을 확인했습니다.
