## 목표

여러 캡처를 보낸 뒤 일반적인 분석 실패 문구만 보이는 문제를 수정합니다. 원본 파일을 유지하고 유료 호출 없이 전송 제한과 오류 안내를 검증합니다.

## 확인한 사실

- 사용자가 보낸 화면에는 세 장의 원본 미리보기와 AI 통합 분석 실패 문구가 있습니다. 사진 속 요청의 서버 기록을 특정하지 못했으므로 정확한 실패 원인은 미확정입니다.
- 운영 API에 분석 불가능한 합성 문자열을 보낸 재현 결과는 작은 요청 `400 application/json`, 4,800,000자 요청 `413 text/plain FUNCTION_PAYLOAD_TOO_LARGE`였습니다. 유효한 이미지를 보내지 않았고 AI 호출 전 입력 검증 또는 플랫폼에서 차단되므로 유료 분석은 실행되지 않았습니다.
- 기존 화면은 JSON이 아닌 오류 응답을 일반적인 AI 실패 문구로 바꿉니다. 개별 이미지 한도와 달리 전체 묶음 요청 용량을 검사하지 않았습니다.

## 수정과 수락 기준

- 전체 JSON 요청을 3,800,000바이트 이내로 준비한 뒤 한 번만 전송합니다.
- 기본 2048px·품질 0.92 설정을 먼저 사용하고, 용량 초과 시 기존 판독 기준의 하한인 2048px·품질 0.85까지 분석용 사본만 다시 인코딩합니다. 원본 선택 파일은 바꾸지 않습니다.
- 이를 넘어서는 묶음은 화질을 계속 낮추거나 AI 호출을 여러 건으로 늘리지 않고 사진을 나눠 추가하도록 안내합니다.
- 413 용량 초과, 504·408 응답 시간 초과, 서버의 한도 메시지를 구분합니다.
- 계산·컴포넌트 테스트, 웹 전체 테스트·타입·빌드, 운영 코드 확인을 수행합니다. 실제 이미지 분석 성공 여부는 별도 승인된 유료 호출 전까지 미검증으로 둡니다.

## 로컬 검증 결과

- 신규 계산·화면 테스트 6개 통과. 용량 초과 사전 차단, 제한된 재인코딩, 판독 품질 하한, 정상 품질 유지, JSON이 아닌 오류 응답 안내를 확인했습니다.
- 웹 전체 74개 파일: 467개 통과, 기존 3개 건너뛰기.
- 웹 TypeScript 검사와 프로덕션 빌드 통과.

## 운영 검증

- 수정 커밋 729e06c 배포가 READY이며 [최신 앱](https://scrave.vercel.app/dashboard?update=729e06c)에 연결됐습니다.
- Python urllib 요청 결과: 대시보드 HTTP 200.
- 배포된 자바스크립트에서 용량 초과 안내·시간 초과 안내와 3,800,000바이트 전송 예산을 확인했습니다. 압축된 코드에서는 숫자가 `38e5`로 표현됩니다.
- 실제 이미지의 AI 분석 성공은 아직 미검증입니다. 승인 전 유료 호출 누적은 0회입니다.
