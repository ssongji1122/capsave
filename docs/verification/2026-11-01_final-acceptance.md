# 목표와 완료 기준

사용자 요청: 앱 기능과 연결별로 하나씩 실제 테스트하고 최종 검수까지 진행합니다. 담당: Codex 현재 대화 세션. 기존 결정 원장과 실제 배포를 우선합니다.

## 연결 시도 기록

- Codex CLI 계정 조회는 성공했습니다. 환경 선택에는 thegoodfriends만 표시됐습니다. 사용자가 Scrave용 필요한 환경 생성을 승인했습니다.
- Gemini CLI 0.66.0: oauth-personal, API 키 환경변수 없음. 같은 원본 3장의 분석 1회 시작 시도는 인증에서 UNSUPPORTED_CLIENT로 종료됐습니다. 분석 완료 0건, 유료 API 호출 0건.
- Aside 브라우저 연결이 이번에 가능해져 실제 웹 설정과 앱 화면 검증을 진행합니다. 브라우저 ChatGPT는 CLI와 달리 로그인 전 상태였습니다.

운영 데이터 삭제·다른 사용자 자료 접근·예약 결제·공개 공유 발행은 실제로 실행하지 않고 승인된 테스트 범위에서 검증합니다. 자동 테스트만으로 실제 서비스 연결을 통과 처리하지 않습니다.

- 운영 비로그인 경계 GET 검증: `/api/guides` → 401 Unauthorized, `/guides` → 로그인 화면(next=/guides), `/settings` → 로그인 화면(next=/settings). 다른 계정 데이터나 운영 데이터를 변경하지 않았습니다.
