목표: 로그인 상태에서 캡처 한 장 선택 → 기존 분석 1회 → 원본 파일 저장 → 계정·본문 기반 공개 게시물 탐색 → 원본 이미지·출처·지도 검색 링크 저장 → 같은 게시물 이미지 넘기기 → 재접속 확인.

승인: 기존 운영 배포 경로 사용. Gemini 실제 분석 1회, US$0.10 이내 승인. 이번 작업의 유료 호출은 0회로 시작하며 테스트 후 실측을 기록한다. 새 DB 마이그레이션·서비스·키 변경 없음.

판정 기준: 원본 캡처 보존, 정확한 게시물 주소끼리만 묶기, 순서와 이전/다음 경계, 세로 스크롤과 이미지 가로 넘기기 분리, 비공개/미노출/오류는 미확인으로 표시, 계정별 접근 통제, 원본 이미지 재열람과 출처·지도 링크 재조회. 휴대폰 크기 브라우저 검증과 실물 폰·네이티브 검증은 구분한다.

구현: 이미지 원본은 기존 개인 Storage에 보존하고 기존 links 열에 인증 이미지 URL을 저장한다. 만료되는 인스타 CDN 주소를 영구 카드 이미지로 사용하지 않는다. 기존의 분리 저장 행은 삭제하거나 마이그레이션하지 않고 정확한 게시물 URL로 묶어 표시한다.

상한: 공개 검색 1회, 게시물 검사 최대 3건, 이미지 최대 20장·장당 5MiB, 미디어 단계 45초. 추가 유료 검색·이미지 분석은 수행하지 않는다. 영상은 포스터와 원본 링크를 보존한다.

검증 결과와 운영 화면 증거는 실제 실행 후 아래에 추가한다.


실제 분석 1회 사용: 서울 낙산공원 캡처. 추가 저장 버튼 없이 장소 분류·계정 저장·정확한 원본 게시물(DdG7y8OCSjM)·Google/Naver 지도 링크 연결을 운영 화면에서 확인했다. 현재 이미지 수집 0건을 부분 실패로 반환했다. 조사 결과 Instagram 이중 이스케이프 URL의 역슬래시가 이중 경로 구분자로 변환되어 CDN 서명이 깨지는 것을 확인했다. URL 복호화 회귀 테스트 RED→GREEN 후 같은 실제 이미지 GET HTTP 200 / image/jpeg / 376792 bytes를 확인했다. 추가 유료 분석 호출은 하지 않는다.

또한 실제 모바일 화면에서 접힌 카드의 기존 CSS가 새 갤러리 div를 숨겼다. data-capture-gallery 예외를 추가했으며 운영 재배포 후 직접 표시·넘기기·재열람을 재검증한다.
