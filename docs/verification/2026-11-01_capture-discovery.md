## 목표와 완료 기준

- 기존 슬레이트 블루·원본 확대·출처·스티커·저장 동작을 유지합니다.
- 웹과 Expo에 같은 정렬 계산을 사용합니다. 기본은 최근 저장순입니다.
- 일정순은 places.date의 유효한 날짜를 사용하며 오늘 이후 날짜를 먼저 표시합니다. 지난 날짜와 날짜 없는 항목은 뒤로 보냅니다. 실시간 예약 조회를 의미하지 않습니다.
- 연관순은 사용자가 선택한 기준 카드의 같은 카테고리에서 태그·장소·출처 계정의 일치를 설명합니다. 근거가 없는 항목은 연관 카드로 추천하지 않습니다.
- 기존 사진 카드를 유지하며, 웹에서는 연관 카드의 원본 미리보기를 함께 표시합니다.
- 한 장씩 보기는 같은 카테고리로 제한합니다. 넘기기로 저장·삭제하지 않습니다.

## 영상과 현재 설정 검토

[참고 영상](https://www.youtube.com/watch?v=B2-hh1NSEFc)의 한국어 자동 자막을 확보했습니다. 자료를 모으고 맥락을 연결하며 중요한 지식을 사람이 선별하는 사례를 참고했습니다. 이를 자동으로 취향을 확정하는 동작으로 확대하지 않았습니다.

기존 Gemini 분석 모델·로그인·저장 한도·환경변수는 변경하지 않았습니다. 신규 유료 호출과 데이터베이스 변경은 없습니다. 정렬은 현재 불러온 카드 범위에 적용됩니다. 외부 검색 결과는 원본 확인을 마친 자료와 구별되는 출처 후보 상태를 유지합니다.

## 검증 기록

- 먼저 실패하는 공통 계산·웹 상호작용 테스트를 작성했습니다.
- 공통 계산: 최근순, 잘못된 날짜, 일정 우선순위, 카테고리 격리, 연결 근거, 기준 카드 유지.
- 웹: 정렬 선택, 기준 변경, 원본 미리보기, 기존 가로 넘김·세로 스크롤·키보드 이동.
- Expo 실기기 로그인과 계정 저장은 별도 인증이 필요합니다. 타입 검증과 테스트를 실기기 완료로 표현하지 않습니다.
- 브라우저 자동화 연결 실패가 발생했습니다. 화면 직접 검증이 복구되기 전에는 새 단계별 화면 캡처를 검증 증거로 제시하지 않습니다.

### 실행 결과

- shared: 24개 파일, 250개 테스트 통과.
- web: 72개 파일, 461개 통과, 기존 3개 건너뛰기. 처음 루트에서 실행했을 때 경로 의존 테스트 3개가 실패했으며, 웹 패키지 디렉터리에서 전체 재실행하여 통과했습니다. 테스트를 비활성화하거나 수정하지 않았습니다.
- mobile: 18개 묶음, 79개 테스트 통과.
- 세 패키지 TypeScript 검사 통과. shared와 웹 프로덕션 빌드 통과.
- 네이티브 홈페이지의 새 조작은 실기기에서 직접 확인하지 못했습니다. 기존 모바일 테스트 통과를 새 화면의 조작 완료 근거로 사용하지 않습니다.

### 배포 권한 복구

첫 배포는 커밋 작성자 접근권한 오류(TEAM_ACCESS_REQUIRED)로 차단됐습니다. 현재 로그인된 소유자 계정과 2026-10-30 복구 기록을 대조했습니다. 기존 커밋·전역 Git 설정·팀 접근권한을 변경하지 않고, 확인된 소유자 이메일을 새 검증 기록 커밋에만 사용해 재배포합니다.

### 운영 배포 확인

- 후속 커밋 00d6f71 배포가 READY이고 [운영 대시보드](https://scrave.vercel.app/dashboard?update=bebacd4)에 연결됐습니다.
- 불변 배포: [검증 버전](https://scrave-xqkpuzy9c-friendspicks-projects.vercel.app). 불변 주소에는 Vercel 접근 보호가 있으므로 휴대폰에는 운영 주소를 사용합니다.
- Python urllib로 운영 대시보드를 요청한 실제 결과: `GET /dashboard: 200`.
- 운영 HTML에 연결된 자바스크립트 파일을 읽은 실제 결과: `연관 기준 카드=true`, `카드 정렬=true`, `일정 가까운순=true`, `같은 태그=true`.
- 첫 검사에서 가운데 점 문자의 번들 이스케이프 때문에 문자열 일치가 실패했습니다. 실제 연결 이유 코드의 가운데 점이 `\\xb7`로 표현된 것을 확인하고 문구를 검사해 통과했습니다.
- 로그인 쿠키 없는 출처 검색 요청의 실제 결과: `POST /api/capture-sources: 401`. 외부 분석 호출은 실행하지 않았습니다.
- 위 검사는 HTTP와 배포 코드 검증입니다. 브라우저 제어 호스트 연결 실패 및 Chrome 창 접근 실패로 새 화면의 직접 조작·캡처 검증은 완료하지 못했습니다. Expo 실기기 인증·계정 저장 검증도 완료로 표시하지 않습니다.
