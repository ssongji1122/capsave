# 검색 근거 표시와 저장·복귀 검증

- 날짜: 2026-11-06
- 담당: Codex, 채팅 01a1af27-204f-7c31-ad00-9472ceda7def
- 기준 커밋: origin/main 000e7a0. 별도 브랜치 feat/search-match-evidence.
- 목표: 검색 카드의 일치 필드와 실제 저장 문장을 표시하고 저장·복귀 동작을 확인합니다.
- 수락 기준: 제목 외 추출문 검색, 복수 필드, 긴 문장, 특수문자, 묶인 카드, 모아보기·한 장씩·분류 확인 필요 영역에서 근거를 유지합니다. 검색어가 없거나 일치 근거를 확인할 수 없으면 표시하지 않습니다.
- 독립 UX 검토: 서버 검색과 기기 검색 의미를 유지하고, 생성 정보와 사진 추출문을 구분하며 실제 저장 문자열만 발췌하도록 반영했습니다.

## 구현

카드 제목·요약 아래에 필드 이름과 검색어 주변 발췌문을 표시합니다. 두 근거를 기본 표시하고 나머지는 펼쳐 확인합니다. 동일 게시물로 묶인 다른 캡처의 제목도 원래 자료에서 가져와 표시합니다. 검색 중에는 이전 결과의 근거를 붙이지 않으며 늦은 응답으로 검색 취소 결과가 덮이지 않도록 요청 순서를 확인합니다. 새로운 분석 호출·데이터 구조 변경은 없습니다.

운영 계정 로그인과 계정 자료 재조회, 신규 계정 저장, 10장 분석·부분 실패 재시도·통신 단절·저장 용량 초과는 미검증입니다. 자동 테스트의 모의 실패 결과를 운영 통과로 취급하지 않습니다. 유료 분석 호출은 0건입니다.

## 검증 근거

- 추가 함수 테스트가 구현 전 6개 실패한 뒤 통과했습니다.
- 관련 함수·화면·기존 저장 테스트: 6개 파일, 29개 통과.
- 타입 검사: tsc --noEmit 종료 0.
- 화면 증거와 임시 입력 도구는 작업 폴더의 _dogfood/search-evidence/에 있습니다. 임시 입력 도구는 앱 경로에서 제거하여 배포에 포함되지 않습니다.
- 빌드: next build 종료 0. 임시 입력 경로가 결과 라우트에 포함되지 않음을 확인했습니다. 기존 다중 잠금 파일 경고가 있으며 빌드 오류는 없습니다.

## 다음 단계와 승인 경계

검색 근거 구현만 공개 변경으로 준비합니다. 저장·복귀 결함은 별도 수정 범위로 기록했습니다. 저장소가 공개이므로 사용자 확인 전 푸시·공개 변경 요청·배포는 실행하지 않습니다. 최신 운영 화면과 원격 main의 차이가 있어 실제 배포 전 기준 버전도 대조해야 합니다.
